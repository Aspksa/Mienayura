# Mienayura

Новый проект. Windows-запускатель `Mienayura.bat` подготовлен.

## Запуск
1. Установите Node.js LTS.
2. Скачайте проект и распакуйте в любую папку, включая внешний SSD.
3. Дважды нажмите `Mienayura.bat`.

BAT запускается из собственной папки, использует `npm.cmd` (без ограничений PowerShell для npm.ps1), устанавливает зависимости через `npm ci` при наличии lockfile или `npm install`, затем выполняет `npm run start`. Ошибки пишутся в `logs/startup.log`.

**Важно:** пока репозиторий пустой и приложения с `package.json` нет, BAT сообщает, что проект ещё не инициализирован. Он не выдаёт ложное сообщение об успешном запуске приложения.
